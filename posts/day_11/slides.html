What it Predicts

Predicting Continuous Output

Linear Regression predicts a continuous numerical value (e.g., salary, price, height) rather than classifying into categories.

🕒
INPUT (x)
Years of Experience
e.g., 5.0 Years
⚙️
MODEL
Linear function
Salary = w * Exp + b
💰
OUTPUT (y)
Predicted Salary
e.g., $85,000

Key Concept: The model looks at historical data points, learns the linear trend (correlation), and projects it to make predictions on unseen variables.

✓ Continuous Value ✓ Linear Dependent

Equation Broken Down

Deconstructing the Math

Don't let the symbols intimidate you. It's just a formula for a straight line:

y Salary
=
w Weight (Slope)
×
x Experience
+
b Bias (y-Intercept)
w

Weight / Slope (w)

How much salary increases per year of experience. If w = $10,000, then each year adds $10k to your paycheck.

b

Bias / Intercept (b)

The starting base salary. The prediction when experience is 0 years. If b = $50,000, that's your baseline starting salary.

Example: Salary = $10k * Experience + $50k

Visualizing the Line

Fitting the Best Straight Line

The model finds the line that goes as close as possible to all data points.

🔴 Residual (Error): The vertical distance between the actual salary (black dot) and the predicted salary on the line. The model adjusts the line to minimize these squared gaps.

Goal: Minimize Residual Sum of Squares (RSS)

How it Learns

Gradient Descent Intuition

How does the model find the best `w` and `b`? It uses **Gradient Descent** — taking small steps downhill to reach the lowest possible error.

1

Predict & Score

Calculate salary predictions and measure error gap (Loss).

2

Adjust Downhill

Tweak `w` and `b` slightly in the direction of lower error.

Iterates automatically until the line stabilizes

When to Use It

When to Choose Linear Regression

Don't reach for complex neural networks first. Use Linear Regression when:

✓

Relationship is Linear

The output changes proportionally with the input. If Years of Experience doubles, salary generally shows a steady upward trend.

✓

Predicting Numeric Output

When you need a continuous numerical output (Salary, Stock Price, Temp) rather than category labels (Spam vs. Not Spam).

✓

Interpretability is Key

You need to explain exactly how every input affects the prediction. Perfect for auditability and establishing a baseline.

💡 Tip: Always use it as your baseline regression model.
